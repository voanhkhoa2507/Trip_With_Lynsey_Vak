# Educational Platform UI Guidelines

When building the UI for this project, you MUST adhere to the following design specifications:

- **Style:** Playful, claymorphism (soft, 3D-like, inflated UI elements).
- **Colors:** Vibrant, engaging colors.
- **Key Sections/Components to include:**
  1. Hero section
  2. Claymorphism cards for features/courses
  3. Course catalog preview
  4. Progress tracking demo
  5. Student testimonials
  6. Enrollment Call-to-Action (CTA)

## Claymorphism Rules
- Use double inner shadows to create the fluffy, 3D look.
- Use soft, rounded corners (`border-radius: 20px` to `40px` depending on size).
- Keep backgrounds light or pastel to let the vibrant colors pop.
- Avoid flat design or sharp edges.

## Typography
- Use modern, rounded or playful fonts (e.g., Quicksand, Nunito, or Poppins).
- Keep headings bold and clear.

Always refer to these guidelines before generating any HTML/CSS/JS for the frontend.
